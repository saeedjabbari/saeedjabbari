# پوشه فونت‌های اختصاصی (Custom Fonts Directory)

این پوشه برای قرار دادن فایل‌های فونت اختصاصی شما در قالب وب آماده شده است.

## فرمت‌های پیشنهادی:
1. `woff2` (بهترین و سبک‌ترین فرمت برای وب مدرن)
2. `woff`
3. `ttf`

## نحوه استفاده:
پس از قرار دادن فایل‌های فونت خود در این پوشه (مثلاً `MyFont-Regular.woff2` و `MyFont-Bold.woff2`):
کافیست اسم فایل‌ها و نام دلخواه فونت را به ما بگویید تا در فایل `src/index.css` به عنوان فونت اصلی سایت تنظیم شود.
